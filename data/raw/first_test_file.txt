Постановка задачи

В рамках данной курсовой работы необходимо решить задачу бинар-
ной классификации для прогнозирования оттока клиентов телекоммуни-
кационной компании.

Для достижения поставленной цели требуется выполнить следующие
этапы:
1) Провести разведочный анализ данных:
• Выполнить загрузку и первичный анализ структуры dataset,
содержащей 20 признаков — числовых и категориальных, и 5282
записи;
• Исследовать распределение признаков, выявить и обработать
пропуски;
• Провести корреляционный анализ числовых признаков и анализ

частотности категориальных признаков, приведенных в табли-
це 4.

2) Реализовать пайплайн предобработки данных:

• Произвести нормализацию числовых признаков с использова-

• Применить one-hot-кодирование для категориальных признаков
с использованием OneHotEncoder;

• Сформировать матрицу признаков X и вектор целевой перемен-
ной y.

3) Построить и обучить модели классификации:
• Реализовать модель логистической регрессии;
• Провести подбор гиперпараметра регуляризации C с помощью
кросс-валидации для максимизации метрики ROC-AUC;
• Реализовать модель градиентного бустинга;
• Обучить модель на данных с использованием категориальных
признаков без предварительного кодирования.

4) Оценить качество моделей:

• Использовать метрику ROC-AUC в качестве основного критерия

Введение

В данной работе рассматривается прикладная задача бинарной клас-
сификации, характерная для сферы телекоммуникационных услуг, — про-
гнозирование оттока клиентов — Customer Churn. На основе исторических

данных о клиентах (длительность обслуживания, структура платежей, де-
мографические характеристики и набор подключенных сервисов) необхо-
димо построить модель, способную с высокой точностью определить ве-
роятность прекращения сотрудничества с компанией. Решение подобной

задачи позволяет бизнесу своевременно выявлять «группу риска» и пред-
принимать целенаправленные меры для удержания клиентов.

В качестве исходных данных используется набор, содержащий 5282

записи, включающий как числовые признаки, так и категориальные, при-
веденных в таблице 4. Целевая переменная Churn является бинарной. Учи-
тывая дисбаланс классов (доля отточных клиентов составляет около 26%),

в качестве основной метрики качества выбрана ROC-AUC, которая устойчи-
ва к данной проблеме и фокусируется на способности модели ранжировать

объекты по вероятности оттока.

Для решения задачи были реализованы и сравнены два подхода. Пер-
вый основан на линейной модели (логистическая регрессия [1]) с предвари-
тельной стандартизацией числовых и one-hot-кодированием категориаль-
ных признаков с использованием библиотеки scikit-learn [2].

Второй подход реализован с помощью градиентного бустинга (биб-
лиотека catboost [3]), который позволяет автоматически обрабатывать ка-
тегориальные признаки и потенциально обеспечивает более высокую точ-
ность.

Для визуального анализа данных и оценки взаимосвязей признаков
применялись библиотеки matplotlib и seaborn.

4.1. Метрика оценки качества

В качестве основной метрики качества выбрана ROC-AUC [1] [2]. Дан-
ный выбор обусловлен следующими причинами:

• устойчивостью к несбалансированным данным;

• способностью оценивать качество ранжирования объектов по веро-
ятности оттока;

• независимостью от выбора порога классификации.

ROC-AUC интерпретируется как вероятность того, что случайно вы-
бранный объект положительного класса будет иметь более высокую пред-
сказанную вероятность, чем случайно выбранный объект отрицательного

класса. Значение метрики лежит в диапазоне [0, 1], где 0.5 соответствует
случайному угадыванию, а 1.0 – идеальному классификатору.

Заключение
В ходе выполнения работы решена задача бинарной классификации
для прогнозирования оттока клиентов телекоммуникационной компании.

Исходный датасет содержал 5282 записи с 20 признаками. В рамках иссле-
дования были выполнены следующие этапы:

• Анализ данных. Проведён разведочный анализ, в ходе которого
выявлен дисбаланс классов, обнаружены и устранены пропуски в
признаке TotalSpent, а также установлены корреляционные связи
между числовыми признаками. На основе выявленного дисбаланса
обоснован выбор метрики ROC-AUC;

• Предобработка данных. Числовые признаки стандартизирова-
ны с использованием Z-нормализации; категориальные признаки

преобразованы методом one-hot-кодирования, что увеличило раз-
мерность матрицы признаков до 47 столбцов. Выполнено стратифи-
цированное разделение выборки на обучающую и валидационную

части;
• Построение и настройка моделей. Реализованы и обучены две

модели: логистическая регрессия с L2-регуляризацией и градиент-
ный бустинг CatBoost с глубиной деревьев 5, коэффициентом обу-
чения 0,05 и ранней остановкой по валидационной метрике;

• Сравнение и итоговое решение. Модель CatBoost показала

незначительно более высокое качество по сравнению с логистиче-
ской регрессией, что объясняется способностью градиентного бу-
стинга моделировать нелинейные зависимости и встроенными ме-
ханизмами обработки категориальных признаков.

Таким образом, поставленная задача решена: разработана модель,

позволяющая с приемлемой точностью идентифицировать клиентов с вы-
сокой вероятностью оттока. Полученные результаты могут быть использо-
ваны для своевременного выявления «группы риска» и принятия мер по

удержанию клиентов.
